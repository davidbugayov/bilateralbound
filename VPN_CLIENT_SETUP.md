# 🔒 Инструкция по подключению к VPN

## Сервер: vpn.emdrbilateral.online (213.139.229.44)

---

## ⚠️ ВАЖНО: Импорт CA сертификата

**Перед подключением к VPN необходимо импортировать CA сертификат!**

Сертификат находится в файле `vpn_ca_certificate.pem` в корне репозитория.

---

## 📱 Android (strongSwan)

### Шаг 1: Установка приложения
1. Скачайте **strongSwan VPN Client** из Google Play
2. Откройте приложение

### Шаг 2: Импорт CA сертификата
1. Скопируйте файл `vpn_ca_certificate.pem` на устройство
2. В приложении strongSwan нажмите ☰ → **CA certificates**
3. Нажмите **⋮** → **Import certificate**
4. Выберите файл `vpn_ca_certificate.pem`
5. Подтвердите импорт

### Шаг 3: Создание VPN профиля
1. На главном экране нажмите **+** (Добавить VPN профиль)
2. Заполните данные:
   - **Gateway:** `vpn.emdrbilateral.online` (или `213.139.229.44`)
   - **Type:** IKEv2 EAP (Username/Password)
   - **Username:** `user1` (или `admin`)
   - **Password:** `SecurePassword123!` (или `AdminPassword789!`)
3. В разделе **Select CA certificate**:
   - Выберите "Show all certificates"
   - Найдите и выберите **VPN root CA**
4. Нажмите **SAVE**

### Шаг 4: Подключение
1. Нажмите на созданный профиль
2. Подтвердите подключение
3. Дождитесь статуса "Connected"

## 🍎 iOS/macOS

### ⚠️ ВАЖНО: Установка в правильном порядке!

**Сначала сертификат, потом VPN профиль!**

### Шаг 1: Установка CA сертификата

1. **Скачайте файл `vpn_ca_certificate.mobileconfig`** из GitHub
2. **Отправьте его себе по email** или через AirDrop
3. **Откройте файл на устройстве**
4. **Установите:**
   - iOS: Настройки → Основные → VPN и управление устройством → EMDR VPN Certificate → Установить
   - macOS: Дважды кликните на файл → следуйте инструкциям
5. **Введите пароль устройства**
6. **Подтвердите установку сертификата**

### Шаг 2: Установка VPN профиля

1. **Скачайте файл `vpn_profile.mobileconfig`** из GitHub
2. **Отправьте его себе по email** или через AirDrop  
3. **Откройте файл на устройстве**
4. **Установите:**
   - iOS: Настройки → Основные → VPN и управление устройством → EMDR VPN → Установить
   - macOS: Дважды кликните на файл → следуйте инструкциям
5. **Введите пароль устройства**

### Шаг 3: Подключение

1. **Откройте Настройки → VPN**
2. **Выберите "EMDR VPN"**
3. **Включите переключатель**
4. **При первом подключении введите:**
   - Username: `user1` или `admin`
   - Password: `SecurePassword123!` или `AdminPassword789!`
5. **Дождитесь статуса "Подключено"**

### Вариант B: Ручная настройка

1. **Импорт сертификата:**
   - Откройте файл `vpn_ca_certificate.pem`
   - Нажмите "Установить" 
   - Перейдите в Настройки → Основные → Профили
   - Установите сертификат

2. **Создание VPN подключения:**
   - Настройки → VPN → Добавить конфигурацию VPN
   - Тип: **IKEv2**
   - Описание: EMDR VPN
   - Сервер: `vpn.emdrbilateral.online`
   - Remote ID: `vpn.emdrbilateral.online`
   - Local ID: оставьте пустым
   - Аутентификация пользователя: **Username**
   - Username: `user1` или `admin`
   - Password: `SecurePassword123!` или `AdminPassword789!`

## 🪟 Windows 10/11

### Шаг 1: Импорт CA сертификата

1. Откройте файл `vpn_ca_certificate.pem` двойным кликом
2. Нажмите **Установить сертификат...**
3. Выберите **Локальный компьютер**
4. Выберите **Поместить все сертификаты в следующее хранилище**
5. Нажмите **Обзор** → выберите **Доверенные корневые центры сертификации**
6. Нажмите **ОК** → **Готово**
7. Подтвердите установку

### Шаг 2: Создание VPN подключения

1. **Настройки → Сеть и Интернет → VPN → Добавить VPN-подключение**
2. Заполните:
   - Поставщик VPN: **Windows (встроенный)**
   - Имя подключения: **EMDR VPN**
   - Имя или адрес сервера: `vpn.emdrbilateral.online`
   - Тип VPN: **IKEv2**
   - Тип данных для входа: **Имя пользователя и пароль**
   - Имя пользователя: `user1` или `admin`  
   - Пароль: `SecurePassword123!` или `AdminPassword789!`
3. Нажмите **Сохранить**

### Шаг 3: Подключение

1. Откройте VPN в настройках
2. Нажмите **Подключить**

## 🐧 Linux (Ubuntu/Debian)

### Шаг 1: Установка клиента

```bash
sudo apt update
sudo apt install network-manager-strongswan
```

### Шаг 2: Импорт сертификата

```bash
# Скопируйте сертификат в системную директорию
sudo mkdir -p /etc/ipsec.d/cacerts
sudo cp vpn_ca_certificate.pem /etc/ipsec.d/cacerts/
```

### Шаг 3: Создание подключения через GUI

1. Откройте **Network Manager**
2. Нажмите **+** → **IPsec/IKEv2 (strongswan)**
3. Заполните:
   - Gateway: `vpn.emdrbilateral.online`
   - Certificate: выберите `vpn_ca_certificate.pem`
   - Authentication: **EAP**
   - Username: `user1` или `admin`
   - Password: `SecurePassword123!` или `AdminPassword789!`
4. Сохраните и подключитесь

## 🆘 Устранение неполадок

### Ошибка: "Не удается проверить сертификат сервера"

**Решение:** Убедитесь, что CA сертификат `vpn_ca_certificate.pem` правильно импортирован:
- Android: strongSwan → CA certificates → должен быть "VPN root CA"
- iOS: Настройки → Основные → Профили → должен быть сертификат
- Windows: certmgr.msc → Доверенные корневые центры → Сертификаты → должен быть "VPN root CA"

### Ошибка: "AUTH_FAILED"

**Решение:**
1. Проверьте правильность логина и пароля
2. Убедитесь, что CA сертификат установлен
3. Попробуйте использовать IP адрес вместо домена: `213.139.229.44`

### Ошибка: "Connection timeout"

**Решение:**
1. Проверьте интернет соединение
2. Убедитесь, что порты 500 и 4500 UDP не заблокированы файрволлом
3. Попробуйте другую сеть (возможно текущая блокирует VPN)
