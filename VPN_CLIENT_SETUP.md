# 🔒 Инструкция по подключению к VPN

## Сервер: vpn.emdrbilateral.online (213.139.229.44)

---

## ⚠️ ВАЖНО: Импорт CA сертификата

**Перед подключением к VPN необходимо импортировать CA сертификат!**

Сертификат находится в файле `vpn_ca_certificate.pem` в корне репозитория.

---

## 📱 Android (strongSwan)

### Шаг 1: Установка приложения
1. Скачайте **strongSwan VPN Client** из Google Play
2. Откройте приложение

### Шаг 2: Импорт CA сертификата
1. Скопируйте файл `vpn_ca_certificate.pem` на устройство
2. В приложении strongSwan нажмите ☰ → **CA certificates**
3. Нажмите **⋮** → **Import certificate**
4. Выберите файл `vpn_ca_certificate.pem`
5. Подтвердите импорт

### Шаг 3: Создание VPN профиля
1. На главном экране нажмите **+** (Добавить VPN профиль)
2. Заполните данные:
   - **Gateway:** `vpn.emdrbilateral.online` (или `213.139.229.44`)
   - **Type:** IKEv2 EAP (Username/Password)
   - **Username:** `user1` (или `admin`)
   - **Password:** `SecurePassword123!` (или `AdminPassword789!`)
3. В разделе **Select CA certificate**:
   - Выберите "Show all certificates"
   - Найдите и выберите **VPN root CA**
4. Нажмите **SAVE**

### Шаг 4: Подключение
1. Нажмите на созданный профиль
2. Подтвердите подключение
3. Дождитесь статуса "Connected"

## 🍎 iOS/macOS

### ⚠️ РЕКОМЕНДУЕТСЯ: Ручная настройка (работает 100%)

iOS/macOS иногда отклоняют установку сертификатов через .mobileconfig. Ручная настройка - надежнее.

### Шаг 1: Установка CA сертификата

**Для iOS:**
1. Скачайте файл **`vpn_ca_certificate.pem`** из GitHub
2. Отправьте его себе по email
3. Откройте email на iPhone/iPad
4. Нажмите на вложение `vpn_ca_certificate.pem`
5. Появится окно "Профиль загружен"
6. Перейдите в **Настройки → Основные → VPN и управление устройством**
7. Нажмите на профиль **"VPN root CA"**
8. Нажмите **"Установить"** (введите пароль)
9. Нажмите **"Установить"** еще раз для подтверждения
10. **ВАЖНО:** Перейдите в **Настройки → Основные → Об этом устройстве → Доверие сертификатам**
11. Включите переключатель для **"VPN root CA"**

**Для macOS:**
1. Скачайте файл **`vpn_ca_certificate.pem`**
2. Дважды кликните на файл
3. Откроется **"Связка ключей"**
4. Выберите **"Вход"** или **"Система"**
5. Нажмите **"Добавить"**
6. Найдите сертификат **"VPN root CA"** в списке
7. Дважды кликните на него
8. В разделе **"Доверие"** выберите **"Всегда доверять"**
9. Закройте окно (введите пароль)

### Шаг 2: Ручное создание VPN подключения

**Для iOS:**
1. **Настройки → Основные → VPN и управление устройством → VPN**
2. Нажмите **"Добавить конфигурацию VPN..."**
3. Выберите тип: **IKEv2**
4. Заполните:
   - **Описание:** EMDR VPN
   - **Сервер:** `vpn.emdrbilateral.online`
   - **Удаленный ID:** `vpn.emdrbilateral.online`
   - **Локальный ID:** (оставьте пустым)
   - **Аутентификация пользователя:** Имя пользователя
   - **Имя пользователя:** `user1` (или `admin`)
   - **Пароль:** `SecurePassword123!` (или `AdminPassword789!`)
5. Нажмите **"Готово"**

**Для macOS:**
1. **Системные настройки → Сеть**
2. Нажмите **"+"** внизу слева
3. Выберите:
   - **Интерфейс:** VPN
   - **Тип VPN:** IKEv2
   - **Имя службы:** EMDR VPN
4. Нажмите **"Создать"**
5. Заполните:
   - **Адрес сервера:** `vpn.emdrbilateral.online`
   - **Удаленный ID:** `vpn.emdrbilateral.online`
   - **Локальный ID:** (оставьте пустым)
6. Нажмите **"Настройки аутентификации..."**
7. Выберите **"Имя пользователя"**
8. Введите:
   - **Имя пользователя:** `user1` (или `admin`)
   - **Пароль:** `SecurePassword123!` (или `AdminPassword789!`)
9. Нажмите **"OK"** → **"Применить"**

### Шаг 3: Подключение

1. **Откройте VPN в настройках**
2. **Переключите "EMDR VPN" в положение ВКЛ**
3. **Дождитесь статуса "Подключено"**

## 🐧 Linux (Ubuntu/Debian)

### Шаг 1: Установка клиента

```bash

sudo apt install network-manager-strongswan
```

### Шаг 2: Импорт сертификата


1. Откройте **Network Manager**
2. Нажмите **+** → **IPsec/IKEv2 (strongswan)**
3. Заполните:
   - Gateway: `vpn.emdrbilateral.online`

   - Authentication: **EAP**
   - Username: `user1` или `admin`

## 🆘 Устранение неполадок

### Ошибка: "Не удается проверить сертификат сервера"

**Решение:** Убедитесь, что CA сертификат `vpn_ca_certificate.pem` правильно импортирован:
- Android: strongSwan → CA certificates → должен быть "VPN root CA"
- iOS: Настройки → Основные → Профили → должен быть сертификат
- Windows: certmgr.msc → Доверенные корневые центры → Сертификаты → должен быть "VPN root CA"

### Ошибка: "AUTH_FAILED"

**Решение:**
1. Проверьте правильность логина и пароля
2. Убедитесь, что CA сертификат установлен
3. Попробуйте использовать IP адрес вместо домена: `213.139.229.44`

### Ошибка: "Connection timeout"

**Решение:**
1. Проверьте интернет соединение
2. Убедитесь, что порты 500 и 4500 UDP не заблокированы файрволлом
3. Попробуйте другую сеть (возможно текущая блокирует VPN)
