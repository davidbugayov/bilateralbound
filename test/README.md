# 🧪 Автоматизированные тесты BilateralBound

Этот каталог содержит автоматизированные тесты для проверки функциональности BilateralBound.

## 📋 Доступные тесты

### 🚀 Основные тесты (`automated-tests.js`)
- ✅ **Проверка здоровья сервера** - проверяет, что сервер отвечает
- ✅ **Создание сессии** - тестирует создание новой сессии
- ✅ **Получение состояния сессии** - проверяет API получения состояния
- ✅ **Движение мяча** - тестирует, что мяч движется на сервере
- ✅ **Отскоки мяча** - проверяет коллизии с границами
- ✅ **Подключение вьювера** - тестирует подключение вьювера к сессии
- ✅ **Подключение контроллера** - тестирует подключение контроллера
- ✅ **Управление мячом** - тестирует паузу, сброс, изменение направления

### 🔄 Тесты синхронизации (`sync-test.js`)
- ✅ **Частота синхронизации** - проверяет, что обновления приходят каждые 50ms
- ✅ **Точность позиции** - проверяет, что мяч движется логично
- ✅ **Обработка границ** - проверяет отскоки от границ экрана

## 🎯 Как запустить тесты

### Через npm скрипты (рекомендуется)
```bash
# Все тесты
npm run test:automated

# Только базовые тесты
npm run test:basic

# Только тесты синхронизации
npm run test:sync

# Быстрые тесты (только критически важные)
npm run test:quick
```

### Напрямую через Node.js
```bash
# Все тесты
node test.js

# Конкретный тип тестов
node test.js basic    # Базовые тесты
node test.js sync     # Тесты синхронизации
node test.js quick    # Быстрые тесты
node test.js all      # Все тесты (по умолчанию)
```

### Отдельные тесты
```bash
# Только базовые тесты
node test/automated-tests.js

# Только тесты синхронизации
node test/sync-test.js
```

## 🔧 Настройка тестов

### Переменные окружения
```bash
# Включить отладочные логи
LOG_LEVEL=DEBUG node test.js

# Изменить порт сервера
PORT=3001 node test.js
```

### Параметры тестов
- **Интервал синхронизации**: 50ms (как в продакшене)
- **Длительность тестов**: 2-5 секунд
- **Таймауты**: 10 секунд для запуска сервера

## 🐛 Отладка тестов

### Если тесты падают
1. **Проверьте, что сервер запущен**:
   ```bash
   npm run status
   ```

2. **Проверьте логи сервера**:
   ```bash
   npm run debug
   ```

3. **Запустите быстрые тесты**:
   ```bash
   npm run test:quick
   ```

### Частые проблемы
- **Порт занят** - тесты автоматически используют существующий сервер
- **Таймауты** - увеличьте время ожидания в коде тестов
- **Сетевые ошибки** - проверьте, что сервер доступен на localhost:3000

## 📝 Добавление новых тестов

### 1. Создайте новый тест
```javascript
async testNewFeature() {
  this.log('Тест: Новая функция');
  try {
    // Ваш тест здесь
    const result = await this.makeRequest('/api/new-endpoint');
    if (result.status === 200) {
      this.log('✅ Новая функция работает', 'success');
      return true;
    } else {
      this.log('❌ Новая функция не работает', 'error');
      return false;
    }
  } catch (error) {
    this.log(`❌ Ошибка теста: ${error.message}`, 'error');
    return false;
  }
}
```

### 2. Добавьте в runAllTests()
```javascript
// В методе runAllTests()
results.newFeature = await this.testNewFeature();
```

### 3. Обновите testNames
```javascript
const testNames = {
  // ... существующие тесты
  newFeature: 'Новая функция'
};
```
