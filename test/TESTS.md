# Тестирование BilateralBound

## 🧪 Универсальный тест синхронизации

Основной тестовый файл: **`test/test-sync.html`**

### 📋 Описание теста

Этот тест проверяет все аспекты синхронизации между контроллером и превью:

- ✅ **Синхронизация движения шарика** между вьювером и превью
- ✅ **Изменение скорости** и корректная передача на сервер
- ✅ **Изменение направления** движения (горизонтально, вертикально, диагонально)
- ✅ **Изменение цвета** шарика и фона
- ✅ **Изменение размера** шарика
- ✅ **Визуализация** в реальном времени

### 🚀 Запуск теста

1. Откройте `http://localhost:3000/test/test-sync.html`
2. Тест автоматически создаст сессию
3. Используйте элементы управления для тестирования
4. Наблюдайте синхронизацию в превью

### 🎮 Функции тестирования

#### **Автоматические тесты:**
- **🚀 Запустить тест** - комплексная проверка всех функций
- **⚡ Тест скорости** - автоматическое изменение скорости от 20% до 100%
- **🧭 Тест направления** - переключение между всеми направлениями
- **🎨 Тест цвета** - циклическое изменение цветов
- **📏 Тест размера** - изменение размера шарика

#### **Ручное управление:**
- **Направление:** Горизонтально, Вертикально, Диагонали
- **Движение:** Старт, Стоп, Сброс в центр
- **Скорость:** Слайдер от 0% до 100%
- **Цвет:** 5 предустановленных цветов
- **Размер:** Маленький (20px), Средний (40px), Большой (80px)

### 📊 Индикаторы синхронизации

- **🔴 Красный индикатор** - ожидание синхронизации
- **🟢 Зеленый индикатор** - успешная синхронизация
- **📝 Лог событий** - детальная информация о всех операциях

### 🔧 Технические детали

- **Polling интервал:** 100ms для плавной синхронизации
- **Canvas превью:** 400x300px с автоматическим масштабированием
- **API endpoints:** Использует стандартные API сессии
- **Обработка ошибок:** Автоматическое логирование всех ошибок

### 📱 Мобильная поддержка

Тест адаптирован для мобильных устройств:
- Адаптивная сетка (1 колонка на мобильных)
- Оптимизированные размеры кнопок
- Touch-friendly интерфейс

## 📝 Логирование

Все тесты автоматически логируют:
- Время выполнения

- Детали команды
