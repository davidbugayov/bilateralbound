# 🚀 SSH Туннели для EMDR сайтов - ГОТОВО!

## ✅ Проблема решена!

Сервер настроен для работы через SSH туннели. Теперь у вас есть **4 альтернативных порта** для доступа к сайтам.

## 🎯 Выполните на локальной машине:

### Вариант 1: Автоматический (Рекомендуется)

```bash
chmod +x start_tunnels.command
./start_tunnels.command
```

### Вариант 2: Ручной

Откройте **4 терминала** и выполните:

```bash
# Терминал 1
ssh -R 8080:localhost:3000 root@213.139.229.44 -p 22

# Терминал 2
ssh -R 8443:localhost:3000 root@213.139.229.44 -p 22

# Терминал 3
ssh -R 8081:localhost:8081 root@213.139.229.44 -p 22

# Терминал 4
ssh -R 8444:localhost:8081 root@213.139.229.44 -p 22
```

## 🌐 Сайты будут доступны локально:

| Сайт | Адрес | Порт | Протокол |
|------|-------|------|----------|
