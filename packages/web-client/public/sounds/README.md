Эта директория содержит звуковые файлы для приложения Bilateral Bound.

Запустите скрипт генерации звуков:

```bash

node generate-sounds.js
```

Это создаст все необходимые звуковые файлы в формате WAV.

## 📥 Как установить скачанные звуки

1. Скачайте звуковые файлы из ссылок выше
2. Переименуйте их в: `tick.wav`, `click.wav`, `bounce.wav`, `tone.wav`
3. Поместите файлы в эту директорию (`/public/sounds/`)
4. (Опционально) Конвертируйте в MP3 для уменьшения размера:

```bash
# Используя ffmpeg
ffmpeg -i tick.wav -b:a 128k tick.mp3
ffmpeg -i click.wav -b:a 128k click.mp3
ffmpeg -i bounce.wav -b:a 128k bounce.mp3
ffmpeg -i tone.wav -b:a 128k tone.mp3
```

5. Если конвертировали в MP3, удалите WAV файлы (опционально)

## 🎨 Требуемые параметры звуков

### 1. `tick.wav/mp3` - Тик-так звук (метроном)
- **Назначение**: Основной звук отскока мяча от границ
- **Характеристики**: Короткий, четкий звук тик-така часов/метронома
- **Длительность**: ~50-100ms
- **Частота**: ~600Hz

### 2. `click.wav/mp3` - Клик звук
- **Назначение**: Альтернативный звук для более резких/точных ощущений
- **Характеристики**: Короткий клик, как у мыши или механической клавиатуры
- **Длительность**: ~20-50ms
- **Частота**: ~800Hz

### 3. `bounce.wav/mp3` - Звук отскока мяча
- **Назначение**: Звук отскока мяча от поверхности
- **Характеристики**: Короткий звук отскока резинового/теннисного мяча
- **Длительность**: ~50-150ms
- **Частота**: ~220Hz (низкая)

### 4. `tone.wav/mp3` - Тональный звук
- **Назначение**: Мягкий тон для терапевтических сессий
- **Характеристики**: Чистый синусоидальный тон 440Hz (нота Ля)
- **Длительность**: ~100-200ms

## 📋 Рекомендуемые параметры файлов

- **Формат**: WAV (без сжатия) или MP3 (для экономии места)
- **Битрейт MP3**: 128-192 kbps
- **Частота дискретизации**: 44.1kHz
- **Каналы**: Моно
- **Размер файла**: < 20KB на звук

## ⚙️ Как работает система

AudioManager автоматически:
1. Пытается загрузить звуковые файлы при инициализации
2. Кэширует загруженные звуки для оптимальной производительности
3. Использует fallback на синтезированные звуки, если файлы недоступны

**Это означает, что приложение работает даже без звуковых файлов!**

## ✅ Проверка установки

После добавления звуков, откройте консоль браузера при запуске приложения.
Вы должны увидеть:

```
Audio files preloaded: 4 of 4
```

Если видите `0 of 4` - звуки не загружены, используется синтез.
