# 🚀 SSH Туннель - Временное решение для доступа к сайтам

## Проблема
Хостинг Beget блокирует порты 80 и 443 по умолчанию. Пока поддержка не разблокирует порты, используйте SSH туннели для локального доступа.

## Шаг 1: Настройка SSH туннелей

### Вариант A: Ручная настройка (Рекомендуется)

Откройте **4 отдельных терминала** и выполните команды:

**Терминал 1** - HTTP туннель для EMDR:
```bash
ssh -R 8080:localhost:3000 root@213.139.229.44 -p 22
```

**Терминал 2** - HTTPS туннель для EMDR:
```bash
ssh -R 8443:localhost:3000 root@213.139.229.44 -p 22
```

**Терминал 3** - HTTP туннель для VPN инструкций:
```bash
ssh -R 8081:localhost:8081 root@213.139.229.44 -p 22
```

**Терминал 4** - HTTPS туннель для VPN инструкций:
```bash
ssh -R 8444:localhost:8081 root@213.139.229.44 -p 22
```

### Вариант B: Автоматическая настройка

Используйте скрипт `start_ssh_tunnel.sh`:
```bash
chmod +x start_ssh_tunnel.sh
./start_ssh_tunnel.sh
```

## Шаг 2: Проверка работоспособности

Запустите скрипт проверки:
```bash
chmod +x test_tunnel_connection.sh
./test_tunnel_connection.sh
```

Ожидаемый результат:
```
✅ EMDR приложение (HTTP) - ДОСТУПЕН
✅ VPN инструкции (HTTP) - ДОСТУПЕН
✅ EMDR приложение (HTTPS) - ДОСТУПЕН
✅ VPN инструкции (HTTPS) - ДОСТУПЕН
```

## Шаг 3: Использование сайтов

После успешного создания туннелей сайты доступны локально:

| Сайт | Адрес | Описание |
|------|-------|----------|
| EMDR приложение | http://localhost:8080 | Основное приложение |
| VPN инструкции | http://localhost:8081 | Инструкции по подключению |
| EMDR приложение (HTTPS) | https://localhost:8443 | Защищенное соединение |
| VPN инструкции (HTTPS) | https://localhost:8444 | Защищенные инструкции |

## Шаг 4: Постоянные туннели

Для постоянной работы добавьте флаги `-N -f`:

```bash
# Фоновые туннели
ssh -R 8080:localhost:3000 root@213.139.229.44 -p 22 -N -f &
ssh -R 8443:localhost:3000 root@213.139.229.44 -p 22 -N -f &
ssh -R 8081:localhost:8081 root@213.139.229.44 -p 22 -N -f &
ssh -R 8444:localhost:8081 root@213.139.229.44 -p 22 -N -f &
```

## Шаг 5: Остановка туннелей

```bash
# Остановить все туннели
pkill -f 'ssh.*213.139.229.44'
```

## Важные замечания

- 🔑 **SSH ключи**: Убедитесь, что настроена беспарольная аутентификация
- 🔒 **Пароль**: Если ключи не настроены, используйте пароль `Nv4TQQnnF%gk`
- 🌐 **Локальный доступ**: Сайты доступны только на вашей локальной машине
- 🔄 **Стабильность**: Туннели могут разрываться, перезапускайте их при необходимости

## После разблокировки портов хостингом

Когда поддержка Beget разблокирует порты 80 и 443, сайты станут доступны по обычным адресам:
- https://emdrbilateral.online
- https://emdrbilateral.ru
- https://vpn.emdrbilateral.online

Туннели можно будет отключить.
