# Решение проблемы с доступом к сайтам на VPS Beget

## Проблема
Ошибка `ERR_CONNECTION_REFUSED` при попытке открыть сайты `emdrbilateral.online`, `emdrbilateral.ru` и `vpn.emdrbilateral.online` указывает на то, что хостинг-провайдер Beget блокирует входящие соединения на стандартных портах (80, 443).

## Причина
Это стандартная политика безопасности VPS серверов на Beget - все входящие порты заблокированы по умолчанию для предотвращения злоупотреблений.

## Решения

### Вариант 1: Обратиться в поддержку Beget (Рекомендуется)

1. **Напишите в поддержку Beget** через личный кабинет
2. **Запросите разблокировку портов** 80 и 443 для вашего сервера
3. **Укажите цель использования** - веб-сервер для EMDR приложения
4. **Дождитесь активации** - обычно занимает от нескольких часов до 1 дня

**Текст запроса в поддержку:**
```
Здравствуйте! Прошу разблокировать порты 80 и 443 для моего VPS сервера.
Сервер используется для размещения веб-приложения EMDR терапии.
IP адрес сервера: 213.139.229.44
Домены: emdrbilateral.online, emdrbilateral.ru, vpn.emdrbilateral.online
Спасибо!
```

### Вариант 2: Использовать Cloudflare (Альтернатива)

1. Зарегистрируйтесь на [cloudflare.com](https://cloudflare.com)
2. Добавьте ваши домены в личный кабинет Cloudflare
3. Cloudflare будет выступать как прокси и перенаправлять трафик на ваш сервер
4. Это решение также улучшит производительность и безопасность

### Вариант 3: SSH туннель для локального тестирования

Используйте скрипт `test_local_tunnel.sh` для создания локального туннеля:

```bash
# Выполните команды из файла test_local_tunnel.sh
chmod +x test_local_tunnel.sh
./test_local_tunnel.sh
```

**Команды для ручного создания туннеля:**

```bash
# HTTP туннель
ssh -R 8080:localhost:3000 root@213.139.229.44 -p 22

# HTTPS туннель
ssh -R 8443:localhost:3000 root@213.139.229.44 -p 22
```

После создания туннеля сайты будут доступны локально:
- http://localhost:8080 - EMDR приложение
- http://localhost:8081 - VPN инструкции
- https://localhost:8443 - EMDR приложение (HTTPS)
- https://localhost:8444 - VPN инструкции (HTTPS)

### Вариант 4: Использовать VPN

Если у вас настроен VPN до сервера, вы можете использовать его для локального доступа к сервисам.
