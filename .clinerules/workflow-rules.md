# Правила рабочего процесса для AI ассистента

## ⚠️ СТРОГО СОБЛЮДАТЬ: Рабочий процесс разработки

### Основная ветка разработки
- **ВСЕГДА** работать ТОЛЬКО в ветке `main`
- **ЗАПРЕЩЕНО** создавать или модифицировать другие ветки без явной команды
- **main** - единственная ветка для разработки и коммитов

### Деплой и ветки релиза
- **main** → деплой на `dev.emdrbilateral.online`
- **stable** → деплой на `emdrbilateral.online` и `emdrbilateral.ru`
- **ЗАПРЕЩЕНО** пушить в `stable` без явной команды пользователя
- **ЗАПРЕЩЕНО** мержить в `stable` без явной команды пользователя

### Процесс деплоя
1. **Разработка:** Все изменения делаются в `main`
2. **Тестирование:** Проверка на `dev.emdrbilateral.online`
3. **Релиз:** Только по команде пользователя - мерж `main` → `stable`
4. **Автоматический деплой:** Webhook'и сами развернут изменения

### Команды для деплоя
- **На dev:** `git push origin main` (автоматически)
- **На prod:** Только по команде: `git checkout stable && git merge main && git push origin stable`

## 🚫 ЗАПРЕЩЕННЫЕ ДЕЙСТВИЯ

1. **НЕ создавать новые ветки** без явной команды
2. **НЕ пушить в stable** без явной команды пользователя
3. **НЕ мержить в stable** без явной команды пользователя
4. **НЕ работать в других ветках** кроме main

## ✅ РАЗРЕШЕННЫЕ ДЕЙСТВИЯ

1. **Коммиты в main** - всегда разрешены
2. **Пуш в main** - всегда разрешен
3. **Чтение любой ветки** - разрешено для анализа
4. **Создание веток по команде** - разрешено только если явно указано

## 📋 Рабочий процесс

### При получении задачи:
1. Убедиться, что находимся в ветке `main`
2. Если не в `main` - переключиться: `git checkout main`
3. Выполнить задачу в ветке `main`
4. Закоммитить изменения
5. Отправить в `main`: `git push origin main`

### При команде на релиз:
1. Получить явную команду: "задеплой на stable" или подобную
2. Выполнить: `git checkout stable && git merge main && git push origin stable`
3. НЕ делать это автоматически

### При проблемах с деплоем:
1. Проверить статус сервисов на сервере
2. Исправить проблемы (порты, зависимости)
3. НЕ трогать ветки без причины
