# EMDR Bilateral Stimulation Project

Проект веб-приложения для EMDR терапии с использованием билатеральной стимуляции.

## 📁 Структура проекта

```
public/
├── index.html              # 🎯 Главная страница - создать сессию
├── index-backup.html       # 💾 Резервная копия оригинальной страницы
├── viewer.html             # 👁️ Страница просмотра сессии
├── test-session-poller.html # 🔧 Тестовая страница API
├── js/                     # 📚 JavaScript модули
│   ├── common.js
│   ├── physics.js
│   └── session-poller.js
├── emdr-therapy/           # 🏥 Профессиональная EMDR терапия
│   ├── index.html          # Полная версия EMDR терапии
│   └── README.md           # Документация EMDR версии
└── README.md              # 📋 Это описание
```

## 🌐 Доступ к страницам

### Основные страницы
- **Главная страница**: `http://localhost:3002/`
- **Вьювер сессии**: `http://localhost:3002/viewer.html`
- **Тестовый поллер**: `http://localhost:3002/test-session-poller.html`

### Специализированные версии
- **EMDR терапия**: `http://localhost:3002/emdr-therapy/`

## 🎯 Назначение страниц

### 🏠 Главная страница (`index.html`)
- Страница создания новой сессии билатеральной стимуляции
- Интерфейс для настройки параметров сессии
- Возможность создания ссылки для зрителя
- Основной рабочий инструмент

### 👁️ Вьювер (`viewer.html`)
- Страница для просмотра сессии клиентом
- Реальное время синхронизации с сервером
- Плавная анимация мяча

### 🏥 EMDR Терапия (`emdr-therapy/index.html`)
- Профессиональная версия EMDR терапии для супружеских пар
- SEO оптимизированная презентационная страница
- Система управления скоростью билатеральной стимуляции
- Интерактивная демонстрация процесса терапии
- Адаптивный дизайн

## 🔧 API Эндпоинты

### Создание сессии
```http
POST /api/session
```

### Управление сессией
```http
POST /api/session/:id/controller/update
GET  /api/session/:id
POST /api/session/:id/controller/connect
POST /api/session/:id/viewer/connect
```

### Параметры стимуляции
- `speedScalar`: скорость движения (0-100)
- `dirX`, `dirY`: направление движения (-1, 0, 1)
- `colorBall`: цвет мяча (hex)
- `colorBg`: цвет фона (hex)
- `radius`: размер мяча (px)

## 🎾 EMDR Концепция

### Билатеральная стимуляция
- **Визуальная**: движение мяча слева направо
- **Аудиальная**: стереозвук (опционально)
- **Тактильная**: вибрация (опционально)

### Фазы терапии
1. **Подготовка**: объяснение процесса
2. **Активация**: стимуляция во время воспоминания
3. **Интеграция**: обработка эмоций
4. **Завершение**: закрепление позитивных изменений
