# EMDR Терапия - Профессиональная версия

## 🎯 Описание

Эта директория содержит полнофункциональную профессиональную версию EMDR терапии для супружеских пар с системой билатеральной стимуляции.

## 🌐 Доступ

Страница доступна по адресу: `http://localhost:3000/emdr-therapy/`

## ✨ Особенности

### 🏥 Профессиональная терапия
- **EMDR терапия** специально для супружеских пар
- **Билатеральная стимуляция** с настраиваемой скоростью
- **Интерактивная демонстрация** процесса терапии

### 🎨 Дизайн
- **Современный интерфейс** с градиентными фонами
- **Адаптивная верстка** для всех устройств
- **Плавные анимации** и микроинтеракции

### ⚡ Система скорости
- **Слайдер скорости** (10-100%)
- **Предустановленные кнопки** (25%, 50%, 75%, 100%)
- **Адаптивная анимация** мяча (3 типа скорости)
- **Динамическое описание** режимов

### 📊 Контент
- **Hero секция** с призывом к действию
- **Показания к терапии** с визуальными карточками
- **Процесс терапии** с пошаговым описанием
- **Преимущества** билатеральной стимуляции
- **Контактная форма** для связи с психологом
